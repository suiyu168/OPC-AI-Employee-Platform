# OPC AI员工平台 数据库模型设计 V1.0

## Company（企业）
保存客户企业基础信息。

字段方向：
- 企业名称
- 行业类型
- 企业配置
- 创建时间

## User（用户）
保存企业使用人员。

字段方向：
- 用户信息
- 所属企业
- 权限角色

## Agent（AI员工）
保存企业AI员工。

字段方向：
- AI员工名称
- 岗位
- 能力配置
- 工作状态

## Task（任务）
保存工作任务。

字段方向：
- 任务名称
- 发布人
- 执行AI员工
- 状态
- 输出结果

## Meeting（会议）
保存AI员工会议记录。

字段方向：
- 会议主题
- 参与Agent
- 会议结果
- 生成文件

## Knowledge（知识库）
保存企业知识。

字段方向：
- 文件来源
- 分类
- 内容索引
- 更新时间

## Log（日志）
保存企业运营记录。
