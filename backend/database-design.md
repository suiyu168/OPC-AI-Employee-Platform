# OPC AI员工平台 数据库设计 V1.0

## 核心数据对象

## 用户表 User
保存企业用户信息。

字段方向：
- 用户ID
- 企业ID
- 登录信息
- 权限角色

## 企业表 Company
保存企业空间信息。

字段方向：
- 企业ID
- 企业名称
- 行业
- 企业资料

## AI员工表 Agent
保存AI员工配置。

字段方向：
- Agent ID
- 岗位名称
- 工作职责
- 所属企业

## 任务表 Task
保存任务流程。

字段方向：
- 任务ID
- 创建人
- 执行员工
- 状态
- 结果

## 会议表 Meeting
保存AI员工会议记录。

## 知识库表 Knowledge
保存企业知识资料。

## 日志表 Log
保存企业经营和AI员工工作记录。
